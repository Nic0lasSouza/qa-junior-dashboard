✅ Checklist final — o que você PRECISA dominar

  • ☐ Fundamentos: níveis, tipos e técnicas (partição, valor limite, tabela de decisão)
  • ☐ Escrever casos de teste + bug report bem feito (Jira/Trello)
  • ☐ Testes de API REST (Postman/Insomnia + automação)
  • ☐ Automação de UI com Cypress (seletores, esperas, Page Object)
  • ☐ SQL básico/intermediário (SELECT, JOIN, GROUP BY, subquery)
  • ☐ Git/GitHub para versionar seus testes
  • ☐ CI básico (GitHub Actions ou Jenkins rodando seus testes)
  • ☐ Docker básico para subir ambiente de teste
Dica final: monte um repositório no GitHub com seus testes Cypress + coleção Postman + queries SQL. Isso vale mais que qualquer certificado na entrevista.
